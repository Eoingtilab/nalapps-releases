# 어잉PDF 2.2.2

## 핵심 변경

- 업데이트 버전·다운로드·SHA-256 정보는 `Eoingtilab/nalapps-releases`가 단일 기준이 됩니다.
- EDD는 라이선스 활성화와 사용 권한 확인만 담당합니다.
- 설치형은 `EoingPDF-2.2.2-Setup-x64.exe`, 포터블은 `EoingPDF-2.2.2-portable.exe`를 직접 받습니다.
- 앱은 다운로드 전후 SHA-256을 검증하고 GitHub 공식 릴리스 자산만 허용합니다.
- PDF 페이지 순서 변경, 썸네일/목록 전환, `더 많은 기능` 메뉴, 저장 버튼 위치 개선을 포함합니다.
- HWP/HWPX 변환 종료 시 원본 문서 저장 확인창이 나타나는 문제를 보완했습니다.

## 배포 태그

`utility-eoingpdf-v2.2.2`
