# 어잉캡쳐 1.0.7

편집한 캡처를 작업 파일로 저장하고 다음에 도형·글자·펜을 다시 수정할 수 있습니다.

- 도구모음 **편집 작업 저장** 또는 **Ctrl+Shift+S**로 `.eoingcapture`에 원본·표시·스타일·실행 취소/다시 실행·자르기·지우개 이력을 보관합니다. 좁은 화면에서는 **더보기**에 있습니다.
- 왼쪽 **작업 파일 열기**에서 편집 파일을 열고 **표시 선택**으로 옮기거나 글자를 고친 뒤 이미지·PDF·Word로 저장할 수 있습니다. 기존 설명 자료 `.eoingreport`도 같은 메뉴에서 열립니다.
- 읽기·렌더 실패나 현재 캡처 닫기 취소 시 기존 작업을 유지합니다. 저장 실패·취소는 저장 완료로 처리하지 않습니다. 읽는 동안 무료 인증이 해제되는 경우와 종료 시 진행 중 작업도 확인했습니다.
- 공용 NALLA 디자인·시스템 라이트/다크·한 줄 아이콘과 기존 캡처·스크롤·OCR·자료 출력 흐름을 유지합니다.

**편집 파일에는 가리기·모자이크 전 원본, 자르기 전 화면, 삭제·취소한 글자와 표시도 들어갑니다.** 다시 수정할 수 있도록 원본을 보관하며 파일은 암호화하지 않습니다. 다른 사람에게 공유할 화면은 일반 **저장(Ctrl+S)**·복사·PDF/Word 출력을 사용하세요. 이 출력은 현재 보이는 결과만 담습니다. 편집 파일에는 외부 원본 경로·키를 넣지 않고 외부 서비스로 자동 전송하지 않습니다.

자르기 후 이전 표시는 기존처럼 그림에 합쳐집니다. 자르기를 실행 취소하면 그 이전 개체를 다시 수정할 수 있습니다. 저장하지 않은 초안의 충돌 후 자동 복원·최근 작업 목록·파일 연결은 아직 제공하지 않습니다. 기존 닫기 확인의 저장은 이미지 저장이므로, 개체를 이어서 수정하려면 **편집 작업 저장**을 사용하세요.

일반 설치는 **EoingCapture-1.0.7-Setup-x64.exe**입니다. EDD 상품30932의 GitHub ZIP 에셋에는 **EoingCapture-1.0.7-Setup-x64.zip**, 포터블에는 **EoingCapture-1.0.7-portable.zip**을 선택하세요. 무료 EDD 키가 필요하며 기존 상품 연결·무료 키 정책을 유지합니다. 이번 변경으로 키를 재발급하거나 인증 정보를 삭제하지 않습니다.

검증: 전체548개 자동 회귀·신규42개, Windows Qt100/125/150% 합성 저장/복원·도형/글자 재수정·정확한 픽셀/원본·라이트/다크·한 줄/더보기 접근, 새 EXE의 편집/자료 작업 파일·작업실·OCR·PDF/Word·고정/지연 진단6개, 별도 QA AppID의 설치/업그레이드/제거·사용자 모사 파일 보존을 확인했습니다. 실제 고객의 모든 업무 앱 스크롤·혼합DPI·물리 입력·OCR 숫자/표 정확도와 업무시간 비교는 계속 진행합니다.
