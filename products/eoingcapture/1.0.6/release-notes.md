# 어잉캡쳐 1.0.6

여러 캡처로 작성하던 설명 자료를 작업 파일로 저장하고, 다음 실행에서 이어서 수정할 수 있습니다.

- **작업 파일 저장**: 이미지·순서·문서 제목·캡처 설명·번호별 설명·출력 옵션을 `.eoingreport`에 함께 보관합니다.
- 왼쪽 **작업 파일 열기**에서 다시 열어 설명과 순서를 고친 뒤 PDF·Word로 출력할 수 있습니다. 원래 보관 이미지가 없어도 열립니다.
- 변경한 자료를 닫거나 앱을 종료할 때 저장을 선택하면 저장 완료 후 닫습니다. 취소·저장 실패 시 작성 내용과 창을 유지합니다.
- 작은 창의 설명 입력란 접근을 개선하고 새 저장 아이콘에도 시스템 밝게·어둡게 전환을 적용했습니다. 기존 공용 NALLA 디자인과 한 줄 편집 도구를 유지합니다.

작업 파일의 그림에는 현재 표시·가림 결과가 PNG로 들어갑니다. 저장한 도형·펜을 개별 개체로 다시 움직이거나 실행 취소하는 편집 프로젝트와 미저장 초안 자동 복구는 아직 제공하지 않습니다. 파일은 암호화하지 않으며 작성한 내용과 그림을 포함하므로 공유 전 확인하세요. 원래 파일 경로·가리기 전 원본·라이선스 키는 포함하지 않고 외부로 자동 전송하지 않습니다.

일반 설치는 **EoingCapture-1.0.6-Setup-x64.exe**, EDD ZIP 에셋 선택은 **EoingCapture-1.0.6-Setup-x64.zip**입니다. 포터블은 **EoingCapture-1.0.6-portable.zip**을 압축 해제해 실행합니다. 무료 EDD 상품30932 키가 필요하며 기존 연결·무료 키 정책을 유지합니다. 같은 Windows 사용자/PC의 인증과 설정은 설치 폴더 밖에서 유지됩니다. 기존 키 재발급·인증 해제 작업은 없습니다.

전체506개 자동 회귀, Windows Qt100/125/150%의 라이트·다크/큰 창·작은 창·설명 탭24상황, 별도 프로세스의 원본 보관 이미지 없는 복원·정확한 픽셀/여러 줄/선행0·한글 긴 경로·손상/취소/쓰기 실패 보호를 검증했습니다. 새 EXE의 작업 파일·작업실·OCR·PDF/Word 출력·고정/지연 합성 진단과 별도 QA AppID의 설치/업그레이드/제거·사용자 모사 파일 보존을 확인했습니다. 합성 진단이며 실제 모든 업무 앱 스크롤·혼합DPI·물리 입력·OCR 숫자/표 정확도 인수는 계속 진행합니다.
