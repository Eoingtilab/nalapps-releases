어잉캡쳐 1.0.13 — 표의 셀을 원본 이미지와 바로 대조

캡처의 글자를 추출한 뒤 표 · Excel에서 셀을 선택하면, 왼쪽 원본에 해당 글자 위치를 표시하고 가운데로 이동합니다. 숫자나 코드를 수정할 때 원본을 다시 찾기 쉬워집니다.

- 맞춤 보기에서 처음 셀을 선택하면 100%로 열고, 직접 고른 확대율은 유지합니다. 표를 열기만 하면 기존 맞춤 보기와 선택 없는 Ctrl+C 전체 표 복사를 유지합니다.
- 셀의 글자를 정정하거나 앞의 행·열을 추가/삭제해도 원본 연결이 따라갑니다. 실행 취소와 다시 실행에서도 같은 위치를 확인할 수 있습니다.
- 직접 추가하거나 인식된 글자가 없는 셀은 원본 위치 없음을 표시합니다. 글자 탭으로 돌아가면 위치 표시를 해제합니다.
- 원본 표시선은 저장·복사하는 이미지에 포함되지 않습니다. 원본 이미지와 인식 결과는 변하지 않으며, 보기 변경 때문에 글자를 다시 읽거나 자동 복사하지 않습니다.
- 기존 공용 시스템 테마·즉시 편집·스크롤·작업 복구·무료 EDD 키를 유지합니다. 외부 OCR 서비스나 새 모델 다운로드는 없습니다.

설치형: EoingCapture-1.0.13-Setup-x64.exe
EDD 설치 자산: EoingCapture-1.0.13-Setup-x64.zip
포터블: EoingCapture-1.0.13-portable.zip
EDD30932는 기존 연결에서 Refresh(선택 전)→새 태그→설치ZIP 선택→Fetch Now→상품 업데이트만 합니다.

검증: 신규14개 포함 전체690회귀(경고 출력 tee-sys 모드), Windows Qt100/125/150%에서 생성 숫자9셀의 원본 위치와 라이트·다크12보기, 실제EXE9진단, 이전1.0.12 편집9PNG 픽셀 동일, 별도QA AppID에서1.0.12→1.0.13 설치·업그레이드·제거와 설치된EXE OCR 확인을 통과했습니다.
한계: 원본 위치는 인식된 글자의 위치이며 글자 정확도나 신뢰도 점수가 아닙니다. 한글 문장·복잡한 표의 오인식이 해결됐다는 뜻이 아니므로 원본과 대조해 수정한 뒤 복사하세요. 실제 Windows 혼합DPI·물리 입력·모든 업무 앱·전체 성능/업무시간 비교는 계속 진행합니다. 기존 기본FD 검사 모드의 자료 복구 정리 중 Qt 중단은 변경 전 소스에서도 재현되며 미해결입니다. 상세 범위·실패 기록은 소스 docs/TABLE_SOURCE_REVIEW.md에 있습니다.

로컬 빌드와 직접 업로드 방식으로 배포하며 GitHub Actions를 사용하지 않습니다. verification.json의 published=false와 소스ZIP 문서의 후보 표기는 게시 전 불변 검증/소스 기록입니다.
