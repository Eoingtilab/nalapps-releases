# 어잉캡쳐 1.0.4

캡처에 표시한 번호별로 설명을 붙여 수정 요청서와 안내 자료를 PDF·Word로 만들 수 있습니다.

- 편집 도구모음의 **번호 설명·자료 만들기**에서 현재 편집본으로 바로 자료를 만듭니다. 좁은 화면에서는 더보기에 있습니다.
- **번호별 설명** 탭에서 각 번호의 수정 요청·안내를 여러 줄로 입력합니다. 이미지의 번호를 유지하며 중간 번호를 임의로 채우거나 다시 매기지 않습니다.
- **편집본 보관** 후 보관함에서 여러 캡처를 체크해 묶을 수 있습니다. 순서를 바꿔도 번호 설명은 해당 이미지와 함께 움직입니다.
- 편집본을 보관하면 번호 목록을 다음 실행에도 읽습니다. 기존 보관 이미지도 호환되며 필요한 번호는 직접 추가할 수 있습니다.
- 미저장 설명의 닫기 확인, 설명이 있는 번호 제거 확인, 저장 실패 후 재시도와 원본·기존 출력 파일 보호를 적용했습니다.

기존 공용 NALLA 디자인, 시스템 라이트/다크, 한 줄 아이콘, 영역·창·전체·세로 스크롤 캡처, 표시 재편집·지우개·실행 취소, 화면 고정·반복·지연, OCR·표 검토와 저장된 EDD 인증 재사용을 유지합니다.

일반 설치는 **EoingCapture-1.0.4-Setup-x64.exe**를 실행하세요. EDD ZIP 전용 목록에서는 **EoingCapture-1.0.4-Setup-x64.zip**이 설치형입니다. 포터블은 **EoingCapture-1.0.4-portable.zip**을 압축 해제해 실행합니다.

무료 EDD 상품30932 키가 필요합니다. 이번 변경에 키 재발급·재등록이나 인증 해제 작업은 없습니다. 같은 Windows 사용자/PC의 기존 키와 사용자 데이터는 설치 폴더 밖에 유지됩니다. 기존 EDD 연결은 새 태그와 설치형 자산 선택만 갱신하면 됩니다.

번호 목록은 표시 기록에 근거한 후보입니다. 지우개로 지우거나 가린 번호, 위치를 알 수 없는 평면 보관 이미지의 번호는 화면과 대조해 직접 확인하세요. 설명이 비어 있으면 문서에 **설명을 입력하지 않았습니다.**라고 표시합니다. 화면당 번호 설명은1,000개까지 지원합니다. 번호 설명의 작업 묶음 파일·초안 자동 복원은 아직 제공하지 않습니다. 저장한 PDF/DOCX와 이미지 보관을 구분해 주세요. 외부 AI 전송은 없습니다.

검증: 전체462개 자동 회귀, 관련 Qt125%/150% 검사, 실제 Windows Qt100%/150% 합성 라이트/다크와 두 창 크기, 직접 PDF 및 실제 Word16.0 렌더 각3페이지의 한글·번호·이미지·선행0 보존, 새 EXE 작업실/OCR/번호별 PDF·Word/고정·지연 진단, 격리 QA 설치·이전판 업그레이드·제거와 사용자 파일 보존을 확인했습니다. 실제 모든 업무 앱 스크롤·붙여넣기·혼합DPI와 OCR 숫자/표 정확도 인수는 계속 진행합니다. 원본과 OCR 결과를 대조해 주세요.
