# 어잉캡쳐 1.0.5

캡처에서 검토한 표를 Excel에 붙여넣을 때 한 셀의 여러 줄이 새 행으로 풀리거나 공백·탭이 바뀌던 문제를 수정했습니다.

- **같은 셀 안 줄바꿈**: 여러 줄과 빈 줄을 원래 셀 안에 유지합니다.
- **원문 유지**: Excel 기본 붙여넣기에서 앞뒤/연속 공백, 탭, 긴 코드와 선행0, 날짜·음수·특수문자를 문자열로 보존합니다.
- **수식 형태도 문자로**: =1+1 같은 내용이 실제 수식으로 실행되지 않도록 명시적인 문자열 표 형식을 함께 제공합니다.

표·Excel 탭에서 원본과 셀을 대조·수정한 뒤 **표 복사 → Excel에서 일반 Ctrl+V**를 사용하세요. 숫자·날짜도 원문 보호를 위한 문자열이므로 계산하려면 원본 대조 후 숫자로 바꾸세요. 강제로 HTML 형식을 선택해 붙여넣으면 셀 안 탭이 공백으로 바뀌는 제한이 있습니다. 다른 앱·Excel 버전의 동작과 OCR 인식 정확도는 별도로 확인해 주세요.

기존 시스템 라이트/다크와 공용 NALLA 디자인, 즉시 편집·복사·저장, 영역·창·전체·세로 스크롤, 지우개·실행 취소·미저장 경고, 표시 재편집, 화면 고정·반복·지연, 로컬 OCR·표 검토 및 번호별 PDF·Word 자료 만들기를 유지합니다. 새 상주 모델이나 외부 전송은 없습니다.

일반 설치: **EoingCapture-1.0.5-Setup-x64.exe**. EDD ZIP 전용 에셋 목록에서는 **EoingCapture-1.0.5-Setup-x64.zip**을 선택하세요. 포터블은 **EoingCapture-1.0.5-portable.zip**을 압축 해제해 실행합니다. 무료 EDD 상품30932 키가 필요하며 같은 Windows 사용자/PC의 기존 인증·설정·캡처 데이터를 유지합니다. 키 재발급·재등록 또는 인증 해제 작업은 없습니다. 기존 EDD 연결은 새 태그와 설치 자산 선택만 갱신하면 됩니다.

검증: 전체466개 회귀, 실제 Excel16.0 새 빈 통합문서의 기본 붙여넣기에서8×4 모든 값/표시/행열/문자열 및 수식0, 기존 클립보드 복원·생산자 종료 후 일치 확인. 실제 새EXE 작업실/OCR/번호별 PDF·Word/고정·지연 진단과 격리 QA 설치·이전판 업그레이드·한글 경로 실행·제거/사용자 파일 보존을 통과했습니다. EXE에서 추출한 컴파일된 표 모듈도 네이티브 Qt 호스트와 Excel로 대조했습니다. 이것을 실제 frozen GUI의 물리 Ctrl+V 입력이나 모든 업무 앱·혼합DPI 인수로 확대하지 않습니다. 실제 OCR 숫자·표 정확도와 업무 앱 스크롤·Word 이미지 붙여넣기는 계속 검증합니다.
