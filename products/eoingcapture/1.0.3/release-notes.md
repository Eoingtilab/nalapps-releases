# 어잉캡쳐 1.0.3

참고 화면을 옆에 두고 작업하며, 같은 위치나 메뉴·팝업 화면을 편하게 캡처할 수 있습니다.

- **화면 고정**: 편집 도구모음/보관함의 압정 아이콘으로 별도 참고 창을 엽니다. 드래그 이동, 휠 확대, Ctrl+휠 투명도, 원본 픽셀 복사·저장과 편집기로 다시 열기를 지원합니다. 새 캡처/스크롤 중에는 고정 창을 숨기고 완료·취소·실패 후 복원합니다.
- **마지막 영역 다시 캡처**: 작업실의 캡처 더보기 또는 트레이에서 이전 선택 영역의 현재 화면을 다시 담습니다. 모니터 배치 변경과 화면 사이의 빈 공간을 확인하고 잘못된 좌표로 캡처하지 않습니다.
- **영역 선택 후 3·5·10초 지연**: 초읽기 동안 대상 앱의 메뉴나 팝업을 열 수 있습니다. 취소·Esc·닫기로 중단하며 취소 후 뒤늦은 캡처를 방지합니다.

기존 공용 NALLA 디자인, Windows 라이트/다크, 한 줄 아이콘, 표시 재편집·실행 취소·지우개·미저장 경고, 영역/창/전체/세로 스크롤, OCR·표 검토·PDF/Word 출력과 저장된 EDD 인증 재사용을 유지합니다.

일반 설치는 **EoingCapture-1.0.3-Setup-x64.exe**를 실행하세요. EDD ZIP 전용 에셋 선택 목록에서는 **EoingCapture-1.0.3-Setup-x64.zip**이 설치형입니다. 포터블은 **EoingCapture-1.0.3-portable.zip**을 압축 해제해 실행합니다.

무료 EDD 상품30932 키가 필요합니다. 이번 변경에 키 재발급·재등록이나 인증 해제 작업은 없습니다. 같은 Windows 사용자/PC의 기존 키와 사용자 데이터는 설치 폴더 밖에 유지됩니다.

고정 창은 이번 실행의 임시 참고 화면이며 파일 저장을 대신하지 않습니다. 최대8창·원본/Qt이미지 추정128MiB 제한이고 확대 시 보이는 구간만 그립니다. 반복은 화면의 고정 물리 좌표이며 이동한 창을 따라가지 않습니다. 앱 재시작 후 고정 창과 반복 좌표의 복원은 제공하지 않습니다.

검증: 전체441개 자동 회귀, 관련 Qt125%/150% 검사, 실제 Windows Qt100%/150% 합성 라이트/다크·타이머·숨김/복원·원본 픽셀 보존, 새 EXE 작업실/고정·지연 타이머/OCR/PDF·Word 출력, 격리 QA 설치·이전판 업그레이드·제거와 사용자 파일 보존을 확인했습니다. 실제 모든 업무 앱 스크롤·붙여넣기·혼합DPI와 OCR 숫자/표 정확도 인수는 계속 진행합니다. 원본과 OCR 결과를 대조해 주세요.
