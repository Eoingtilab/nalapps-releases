# 어잉캡쳐 1.0.8

큰 캡처를 표시하고 편집할 때 불필요한 전체 이미지 복사를 줄였습니다. 기존 캡처·스크롤·주석·작업 파일·문서 출력과 공용 디자인을 유지합니다.

- 일반 RGB 캡처는 불필요한 RGBA 변환 버퍼 없이 Qt 이미지로 전달합니다. 투명도·팔레트·색상키 이미지는 기존 알파를 유지합니다.
- 확정된 표시와 임시 형광펜·글자·번호·지우개를 그릴 때 중복된 전체 픽셀 복사를 줄입니다. 원본·자르기·실행 취소 이력과 Qt 이미지의 수명은 보존합니다.
- 같은 PC의 소스 Qt/Pillow 합성 측정에서 800×20,000px 이미지 변환 중앙69.73→39.31ms, 검증 프로세스 최대 메모리292.76→200.82MiB였습니다. 4K 변환34.35→17.25ms,174.65→127.00MiB였습니다. 각 연산은 별도 프로세스의3회 준비+15회 측정이며 앱 전체 상주 메모리나 실제 캡처→편집 속도 달성으로 해석하지 않습니다.
- 실제 Word16.0 기본 붙여넣기 API 네 경우의 DOCX에서 원본 픽셀·비율·자르기 없음이 유지됐습니다. 편집창 닫힘·1920×1080·긴 이미지도 확인했습니다. 소스 Qt 검증이며 실제 설치 GUI의 물리Ctrl+V 인수는 별도입니다.

전체563개 회귀·신규15개, Windows Qt100/125/150% 라이트/다크·복원·작은 툴바/편집 결과의 이전1.0.7 소스 PNG15개 전체픽셀 일치, 실제 새EXE 진단6개·이전1.0.7 EXE PNG5개 전체픽셀 일치, 별도 QA AppID의 설치/업그레이드/제거·사용자 모사 파일 보존을 확인했습니다. 실제 업무 앱의 모든 스크롤·혼합DPI·물리 입력·OCR 숫자/표 정확도·상주 메모리/전체 반응·업무시간 비교는 계속 진행합니다. 자동 초안 복원은 아직 제공하지 않습니다.

일반 설치는 **EoingCapture-1.0.8-Setup-x64.exe**, EDD 상품30932의 ZIP 에셋은 **EoingCapture-1.0.8-Setup-x64.zip**, 포터블은 **EoingCapture-1.0.8-portable.zip**입니다. 기존 상품 연결·무료 EDD 키 필수 정책과 인증 저장 위치를 유지합니다. 이 변경으로 키를 재발급하거나 인증 정보를 삭제하지 않습니다.

1.0.7의 `.eoingcapture` 편집 작업 저장·열기는 계속 지원합니다. **편집 파일에는 가리기·자르기 전 원본과 삭제·취소한 글자/표시도 들어갑니다.** 공유는 현재 결과만 담는 일반 이미지 저장·복사·PDF/Word 출력을 사용하세요.
