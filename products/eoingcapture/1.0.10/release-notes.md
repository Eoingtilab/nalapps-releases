어잉캡쳐 1.0.10은 고정 메뉴가 있는 세로 스크롤 캡처를 개선합니다. 확인 가능한 상단 메뉴와 하단 바는 한 번씩 남기고, 겹치는 본문만 이어 붙입니다. 메뉴가 바뀌거나 겹침이 불확실하면 멈추고 지금까지의 결과를 유지합니다. 상태 문구가 길어질 때도 패널 버튼이 화면 안에 보이도록 했습니다.

스크롤 캡처 → 영역 선택 → 기본 옵션 ‘고정 상단 메뉴·하단 바는 한 번만 포함’ → 자동 시작 또는 직접 화면 추가 → 완료·편집 순서입니다. 기존 즉시 주석·복사·저장·편집 복구·공용 다크/라이트 디자인을 유지합니다.

검증: 전체623개 회귀, 실제 Chrome 100% 합성 페이지 자동11장→760×2800·직접 완료·보이는 본문과 고정64/48px의 픽셀 일치. Windows Qt100/125/150% 합성 연결·메뉴 변경 보호·편집 전달·패널 테마 검증. 새 EXE 진단8경로와 고유 QA AppID의 격리 설치·업그레이드·제거·사용자 모사 파일 보존을 확인했습니다.

제한: 메뉴에 가려 한 번도 보이지 않은 픽셀은 복원하지 않습니다. 가로 스크롤·전체 웹 렌더·모든 브라우저/Office/물리 혼합DPI의 호환 검증은 아닙니다. 불확실한 고정 경계는 움직이는 본문만 선택합니다.

설치형은 EoingCapture-1.0.10-Setup-x64.exe, EDD 에셋 목록용 설치 ZIP은 EoingCapture-1.0.10-Setup-x64.zip입니다. 포터블 ZIP은 별도로 제공합니다. 소스 ZIP·업데이트 정보·SHA256SUMS·검증 기록을 함께 제공합니다. verification.json의 published=false는 게시 전 불변 파일 검사 기록이며 공개 상태는 이 릴리스 페이지를 기준으로 확인합니다.

무료 EDD 상품30932 키 필수 정책과 기존 인증 저장을 유지합니다. 이미 연결된 EDD는 새 태그와 Setup ZIP만 선택·Fetch Now·상품 저장하면 됩니다. 관리자 상품 저장이나 재연결은 수행하지 않았습니다.

로컬 빌드·직접 릴리스 업로드 방식입니다. GitHub Actions를 사용하지 않습니다. 제품별 업데이트 정보만 반영하고 공용 latest와 다른 제품은 유지합니다. 이번 개선만으로 전체 제품 목표 완료나 세계 최고로 판정하지 않습니다.
