어잉캡쳐 1.0.9 — 저장하지 못한 편집 이어서 작업하기

캡처에 글자나 표시를 넣던 중 앱이 비정상 종료되면, 다음 실행의 작업실에서 ‘작업 복구’를 선택해 이어서 수정할 수 있습니다. 입력 중 글자를 확정하거나 커서를 움직이지 않고 내 PC에 원본·도형·글자·자르기·실행 취소 이력을 임시 보관합니다.

- 기본 설정: 설정 → 저장 → 저장하지 않은 편집 자동 복구.
- 기존 완성본은 새 저장 실패·취소·저장 도중 종료에도 유지합니다. 복구한 작업은 미저장 상태로 표시하며 저장 성공 또는 명시적인 닫기 때 해당 복구본만 정리합니다.
- 복구본은 내 PC의 LocalAppData에만 보관합니다. 최대 10개/512MiB를 목표로 제한하며 목록에서 직접 지울 수 있습니다. 끄면 새 보관을 중단하고 기존 복구본은 남습니다.
- 원본 화면과 삭제·취소한 표시도 복구 파일에 포함됩니다. 처음 저장되기 전이나 마지막 주기/파일 작성 중 새 변경은 잃을 수 있으므로 정상 파일 저장을 대신하지 않습니다.
- 기존 빠른 캡처·한 줄 아이콘·공용 라이트/다크 테마·무료 라이선스·앱 업데이트를 유지합니다. 설명 자료의 자동 초안 복구는 별도 후속 기능입니다.

Windows x64 설치형은 Setup-x64.exe, EDD용 설치형 ZIP은 Setup-x64.zip, 포터블은 portable.zip입니다. EDD 상품 30932의 기존 연결과 무료 키 정책을 유지하고 태그 utility-eoingcapture-v1.0.9 및 EoingCapture-1.0.9-Setup-x64.zip만 갱신하면 됩니다.
