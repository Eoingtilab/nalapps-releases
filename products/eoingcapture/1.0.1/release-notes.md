# 어잉캡쳐 1.0.1

기존 1.0.0 설치본에서 변경 버전을 구분하고 업데이트할 수 있도록 버전을 올렸습니다. 캡처 직후 편집과 저장하지 않은 작업 보호, 저장된 인증의 시작 과정을 개선했습니다.

- 같은 PC에 저장된 키가 있으면 입력창 없이 자동 확인하여 앱을 엽니다. 확인이 늦을 때만 진행 화면을 표시하며, 통신 실패 시 저장된 키로 다시 확인할 수 있습니다. 재등록이나 기기 인증 해제를 자동으로 수행하지 않습니다.
- 캡처 영역 바깥에 테두리를 유지합니다. 테두리는 저장·복사 이미지에 들어가지 않습니다.
- 부분 지우개로 추가한 표시를 지우고 원본 화면을 복원합니다. 실행 취소/다시 실행과 자르기 후 지우기를 지원합니다.
- 한 줄 도구모음에 지우개·실행 취소·다시 실행을 앞쪽에 배치하고, 아이콘에 마우스를 올리면 메뉴 이름과 사용 방법을 표시합니다.
- 저장하지 않은 편집을 닫을 때 저장/저장하지 않고 닫기/취소를 선택합니다. 저장 실패나 취소 시 편집을 유지합니다.
- 기존 공통 테마·시스템 밝게/어둡게, 영역/전체/창/스크롤 캡처, OCR 글자·표 검토, PDF/Word 자료 만들기를 유지합니다.

설치하려면 **EoingCapture-1.0.1-Setup-x64.exe**를 사용하세요. 포터블은 별도 ZIP을 압축 해제해 실행합니다. EDD ZIP 선택 화면에서는 **EoingCapture-1.0.1-Setup-x64.zip**이 설치형 파일입니다. Release Source Code는 설치 프로그램이 아닙니다.

무료 EDD 상품30932 키 인증은 처음 한 번 필요합니다. 같은 Windows 사용자/PC에서 업데이트 후 기존 저장 키를 재사용하고 실행할 때 서버 상태를 확인합니다. 키·설정·캡처 파일은 설치 디렉터리 밖에 보존됩니다.

검증: 전체365개 자동 회귀 통과. 실제 Windows 사용자에 저장된 유효 키로 별도 두 프로세스의 시작 확인을 수행해 입력창/재등록 없이 통과했고 키·기기 식별값이 유지됐습니다. 이전 편집 회귀의 Qt125%/150% 배율도 통과했습니다. 파일별 SHA-256은 SHA256SUMS.txt를 확인하세요.

실제 혼합 DPI 구성과 모든 업무 앱의 스크롤·붙여넣기 호환성은 추가 검증 중입니다. OCR 결과의 글자·숫자는 원본과 대조하세요. 이 릴리스는 모든 환경의 검증이나 최고의 제품이라는 판정을 뜻하지 않습니다.

앱은 로컬에서 빌드했습니다. 소스 커밋과 검증 정보는 소스 ZIP 및 verification.json에 포함합니다.
