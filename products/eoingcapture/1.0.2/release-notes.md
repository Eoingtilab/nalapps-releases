# 어잉캡쳐 1.0.2

캡처에 그린 표시를 다시 선택해 위치와 내용을 고칠 수 있도록 편집 기능을 개선했습니다.

- 팔레트에서 표시 색상, 선 굵기(2/4/8/12px), 글자·번호 크기(18/24/32/48px)를 조절합니다. 형광펜 색을 별도로 기억하며 같은 실행 세션의 다음 캡처에도 기본 스타일을 유지합니다.
- 표시 선택 아이콘으로 도형·펜·글자·번호·가림 범위를 옮깁니다. 도형의 네 모서리와 화살표 끝점으로 크기를 조절합니다.
- 글자는 더블클릭 또는 Enter로 수정하고 Delete로 선택한 표시를 삭제합니다. 방향키는1px, Shift+방향키는10px 이동합니다.
- 이동·크기·스타일·글자 수정을 실행 취소/다시 실행할 수 있습니다. 선택 테두리와 조절점은 저장·복사 이미지에 들어가지 않습니다.
- 기존 한 줄 아이콘 도구모음, 시스템 라이트/다크, 미저장 경고, 영역·전체·창·세로 스크롤, OCR·표 검토, PDF/Word 출력과 저장된 EDD 인증 재사용을 유지합니다.

일반 설치는 **EoingCapture-1.0.2-Setup-x64.exe**를 실행하세요. EDD의 ZIP 전용 에셋 선택 목록에서는 **EoingCapture-1.0.2-Setup-x64.zip**이 설치형입니다. 포터블은 별도 portable.zip을 압축 해제해 실행합니다.

무료 EDD 상품30932 키가 필요합니다. 같은 Windows 사용자/PC의 기존 키와 사용자 데이터는 업데이트 후 유지합니다. 이번 변경에 라이선스 재등록이나 해제 작업은 없습니다.

지원 범위: 새로 추가한 표시를 현재 편집창에서 수정합니다. 자르기는 이전 표시를 이미지에 합치므로 자르기 전 표시를 개별 편집하려면 먼저 자르기를 실행 취소하세요. 부분 지우개 영역은 캡처 좌표에 남습니다. 저장된 PNG/JPG를 다시 열어 편집 개체를 복원하는 프로젝트 기능은 아직 없습니다.

검증: 전체398개 자동 테스트, Qt 배율125%/150%의 관련 편집 검사, Windows 합성 창의 이동·크기·글자·저장/복사 픽셀 대조, EXE 작업실/OCR/PDF·Word 출력, 격리 설치·업그레이드·제거 및 사용자 파일 보존 확인. 실제 모든 업무 앱의 스크롤·붙여넣기와 혼합DPI 검증은 계속 진행합니다. OCR 숫자와 글자는 원본과 대조해 주세요.
