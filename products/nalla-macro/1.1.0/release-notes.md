# 날라매크로 v1.1.0

Windows용 무료 키보드·마우스 매크로 유틸리티 정식 안정화 버전입니다.

## 주요 기능
- 키보드 입력 및 키 누르기/유지
- 마우스 이동·클릭·더블클릭·휠
- 횟수 지정 및 시간 지정 반복
- 초 단위 대기와 실행 단계 카운트다운
- 단계 복사·삭제·순서 변경·선택 단계 아래 삽입
- 매크로 저장 및 불러오기
- 실행 중 일시정지·중지 및 긴급 중지 단축키
- 날라매크로 전용 인트로 및 애플리케이션 아이콘
