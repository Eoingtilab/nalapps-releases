# 날라액션 v1.0.0

날라액션의 첫 정식 안정 버전입니다.

## 주요 기능

- Windows 전역 마우스 이동·버튼·휠 녹화 및 재생
- 키보드 일반키 및 Ctrl/Alt/Shift/Win 조합키 녹화 및 재생
- 녹화 후 저장 없이 즉시 실행
- 녹화 시작/중지와 실행/중지 2버튼 제어
- `Ctrl + Shift + F12` 전역 긴급 중지
- 액션 단계 추가·편집·삭제·활성/비활성·순서 변경
- 텍스트 입력 및 대기 시간 수동 단계
- `.nlaction` 저장·불러오기
- 비정상 액션 파일 검증과 원자적 저장
- 날라액션 자체 UI 동작 녹화 제외
- NALLA APPS 인트로와 프로그램 중앙 실행
- 날라액션 전용 Windows 아이콘

## 환경

- Windows 10/11 x64
- self-contained .NET 8 single-file 실행 파일

## 알려진 제한

관리자 권한 프로그램을 자동화하려면 날라액션도 동일한 권한 수준으로 실행해야 합니다. UAC Secure Desktop, 잠금 화면과 같이 Windows가 입력 주입을 차단하는 보안 화면은 자동화 대상이 아닙니다.
